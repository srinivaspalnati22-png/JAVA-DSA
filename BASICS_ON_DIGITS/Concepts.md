## 📖 Part 1: Core Mathematical Definitions

| Concept | Definition | Mathematical Intuition / Example |
| :--- | :--- | :--- |
| **Dividend** | The number being divided | In $27 \div 4$, **$27$** is the Dividend |
| **Divisor** | The number used for division | In $27 \div 4$, **$4$** is the Divisor |
| **Quotient** | The integer answer after division | In $27 \div 4$, **$6$** is the Quotient (`27 / 4 = 6`) |
| **Remainder** | The leftover value after division | In $27 \div 4$, **$3$** is the Remainder (`27 % 4 = 3`) |
| **Multiples** | Numbers generated by multiplication | Multiples of $3$: $3, 6, 9, 12, 15, \dots$ |
| **Factors / Divisors** | Numbers that divide a number completely (Remainder = 0) | Factors of $12$: $1, 2, 3, 4, 6, 12$ |
| **Even Number** | Any integer divisible by 2 | $n \pmod 2 == 0$ (e.g., $0, 2, 4, 6, \dots$) |
| **Odd Number** | Any integer not divisible by 2 | $n \pmod 2 \neq 0$ (e.g., $1, 3, 5, 7, \dots$) |
| **Prime Number** | A number $> 1$ with **exactly 2 factors** (1 and itself) | $2, 3, 5, 7, 11, 13, 17, \dots$ |
| **Composite Number** | A number $> 1$ with **more than 2 factors** | $4, 6, 8, 9, 10, 12, \dots$ (Note: $1$ is neither prime nor composite) |
| **Prime Factors** | Prime numbers that divide a number completely | Prime factors of $60$: $2, 3, 5$ ($60 = 2^2 \times 3 \times 5$) |
| **GCD (Greatest Common Divisor)** | The largest positive integer that divides both numbers | $\gcd(12, 18) = 6$ |

## 🛠️ Part 2: Prerequisites for Problem Solving (Digit Manipulation)

### 1. Extracting the Last Digit
- **Formula:** `lastDigit = n % 10;`
- **Example:** $1234 \pmod{10} = 4$

### 2. Removing the Last Digit
- **Formula:** `n = n / 10;`
- **Example:** $1234 / 10 = 123$

### 3. Extracting All Digits One by One (Right to Left)
```java
while (n > 0) {
    int digit = n % 10;   // 1. Extract last digit
    // Process the digit (e.g., count, sum, check, print)
    n = n / 10;          // 2. Discard last digit
}
```

### 4. Building / Reversing a Number Digit by Digit
To append a `digit` to an existing number `num`:
- **Formula:** `num = (num * 10) + digit;`
- **Example:** If `num = 12` and we want to append `3`:
  $$12 \times 10 + 3 = 120 + 3 = 123$$

### 5. Inserting a New Digit
- **At the end:** `num = num * 10 + newDigit;`
- **At a specific position:** Split using powers of 10 (`% 10^k` and `/ 10^k`), insert, and recombine.

### 6. Removing All Occurrences of 'a' (or Factor 'a') from a Number
- **Removing a factor $a$ (e.g., remove all 2s or 3s dividing $n$):**
  ```java
  while (n % a == 0) {
      n = n / a;
  }
  ```
- **Removing a specific digit $d$ from a number:**
  Extract digits, filter out $d$, and reconstruct the number in original order.
